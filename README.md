# Amount Record and Streaming Example

This repository contains a simple money record application built with HTML and Firebase. 

A minimal streaming platform example using Node.js and Express has been added. 

## Running the Streaming Example

1. Install dependencies (requires internet access):
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Visit `http://localhost:3000` in your browser to play sample videos.

The `public/` directory contains the streaming page served by `server.js`.
